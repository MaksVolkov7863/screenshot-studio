# СкринСтудия 2.0

Расширение Firefox (Manifest V3): захват страниц, GIF, история и редактор аннотаций.

## Захват

- область (несколько кусков → коллаж), копировать / сохранить / пин / поиск прямо на оверлее
- видимая область, вся страница (бейдж + отмена)
- элемент; **Shift+клик** — скролл внутри элемента
- скролл колонки / чата
- таймер 3/5/10 сек с паузой и «снять сейчас»
- ждать модалку / изменение DOM
- скрыть UI сайта (sticky, cookie, чат, клик по элементу)
- GIF области 5–15 с, видео прокрутки страницы
- кадр из `<video>`
- снимок выделенного текста (контекстное меню)
- курсор и кружок клика
- повтор последнего режима (`Alt+Shift+R`)

## Редактор

- кривые стрелки (средняя точка), выноска с кончиком
- шаблоны «Баг» и «До/После»
- слайдер сравнения двух снимков
- линейки, сетка, размер в px
- логотип, водяной знак, рамка браузера/телефона
- Shift-мультивыбор и выравнивание
- сглаживание пера, лазер
- шаги: 1, I, A, a, А, а и подшаги `1.2`
- светлая/тёмная тема, компактная панель
- карта длинного снимка, OCR, PDF, печать, загрузка ImgBB
- запоминаются инструмент и цвет

## Куда девается снимок

История (до 30 + избранное), тихий режим в буфер с превью, пин-окно поверх, имя `{site}-{title}-{date}` и папка `Screenshots/домен`.

## Установка

Репозиторий: https://github.com/MaksVolkov7863/screenshot-studio

`about:debugging` → временное дополнение → `manifest.json`. После обновления кода нажмите **Обновить** у расширения.

Готовые **zip** и **xpi** появляются в [Releases](https://github.com/MaksVolkov7863/screenshot-studio/releases) после тега `v*`.

```
python scripts/ci_check.py
python scripts/pack.py
```

Релиз: `git tag v2.1.1 && git push origin v2.1.1` — GitHub Actions проверит код, соберёт архивы и опубликует релиз.

**OCR** работает в редакторе через Tesseract, без установки на Windows. Первый раз скачаются языковые файлы (рус/англ) в браузер.

**Защищённые страницы** (`about:`, AMO, PDF): Firefox не отдаёт вкладку расширению, поэтому снимается само окно браузера (нужен тот же `native\install-ocr-host.ps1`, что и раньше). Обрежьте кадр в редакторе.
